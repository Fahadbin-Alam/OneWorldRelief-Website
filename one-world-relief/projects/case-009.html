Mosque Support · Case 009

Twenty Ceiling Fans for a New Mosque

One World Relief's documented completion update reports that 20 ceiling fans were installed at a newly built mosque in Bangladesh. The installation update was shared on September 24, 2025. One World Relief later confirmed the completed project cost was $1,650.

Overview

What this case provided

The supplied project record and saved completion update document 20 ceiling fans successfully installed in a newly built mosque in Bangladesh. One World Relief has now confirmed the completed project cost was $1,650.

The number of people served was not listed in the supplied records, so this page does not estimate that figure. Case 009 is complete; the separate $1,000 mosque-support donation option is for future mosque projects and is not the cost of this case. Private correspondence, phone numbers, donor names, and embedded photo metadata are not included in the public case record.
